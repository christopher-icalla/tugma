TUGMA · Independent verification

Check an evidence package against Stellar

Choose a package file downloaded from TUGMA. This page rebuilds its canonical form, recalculates the SHA-256 hash and reads the attestation directly from the Stellar Testnet contract through Soroban RPC. It never contacts TUGMA's servers, and the file never leaves your browser.

Network settings

The contract is set here, never taken from the file. Defaults are TUGMA's public Testnet deployment.

A valid result establishes package integrity: the file is exactly the package attested on Stellar. It does not establish that the contents are true or that the organization is compliant.

Open source (MIT): verifier/ in the TUGMA repository. The same checks run from the command line with tugma-verify.
